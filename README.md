# Is AI Helping You Think—or Thinking For You?

An interactive, research-based genre translation website about generative AI, cognitive offloading, and critical thinking.

## View locally
Open `index.html` in a web browser. No installation or build step is required. The Google Fonts stylesheet requires an internet connection; system-font fallbacks work offline.

## Publish with GitHub Pages
1. Create a **public** repository named `ai-thinking-website` on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the **root** of the repository (not into a nested folder).
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main`, folder `/(root)`, and **Save**.
6. After publishing completes, open `https://YOUR-USERNAME.github.io/ai-thinking-website/`.

Content is educational, and self-reflection activities are not clinical or scientific diagnostic tests.
